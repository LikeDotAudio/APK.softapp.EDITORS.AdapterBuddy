# EDITORS.AdapterBuddy — Adapter & Media Balun Buddy

**Wiki:** [Documentation/README.md](Documentation/README.md) — principles, architecture, delivery.

Adapter & Media Balun Buddy: configure inline signal adapters, audio baluns, HDMI-to-SDI converters, XLR barrel turnarounds, gender changers, and pinout translation matrices.

| | |
|---|---|
| **Opens** | the OS shell (Design → Hardware & Devices), or `index.html` standalone |
| **Build** | none — plain web files; `npm test` |
| **Ships** | baked into WEB.Frontend-Assets (`up-stack.sh WEB.Frontend-Assets`), served at `:8080/Softapps/EDITORS/EDITORS.AdapterBuddy/` |
